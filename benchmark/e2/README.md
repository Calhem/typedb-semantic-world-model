# Stage E2 benchmark (not authored yet)

This directory will hold the Stage E2 evaluation: reader contracts, fixtures, questions, calculation sheets and gold
answers (design: [docs/stage-e/stage-e2-evaluation-design.md](../../docs/stage-e/stage-e2-evaluation-design.md);
decisions: [docs/stage-e/stage-e2-decisions.md](../../docs/stage-e/stage-e2-decisions.md)).

**No fixture, question, calculation sheet or gold answer is written yet.** Authoring starts only after the owner
approves the reader contracts (E2-D3).

What is here now:
- `spec/reader-contracts.md`: the E2 reader contracts (E2-D3). Drafted under LABS-1.062; proposals approved with
  qualifications under LABS-1.063 (§0.10); still at review for final approval. Review packages:
  [stage-e2-reader-contracts-review.md](../../docs/stage-e/stage-e2-reader-contracts-review.md) and
  [stage-e2-labs-1063-review.md](../../docs/stage-e/stage-e2-labs-1063-review.md).
- `spec/blocked.json`: the unresolved semantic decisions; the question checker refuses questions that depend on one.
- `spec/reader-docs.md`: the documentation strings of every reader the E2 harness can call, generated by
  `evaluation/e2/reader_docs.py` (GAP-HARNESS-4). These are the readers' own descriptions of themselves, a supplement
  to the contracts and not a replacement for them.

The harness that will run E2 is `evaluation/e2/`. Its review is
[docs/stage-e/stage-e2-harness-review.md](../../docs/stage-e/stage-e2-harness-review.md). Its tests use only the synthetic
fixture `tests/fixtures/e2/harness-synthetic.json`, which is not an E2 evaluation fixture.
