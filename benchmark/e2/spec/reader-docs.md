# Documented semantics of the readers the Stage E2 harness can call

Generated by `evaluation/e2/reader_docs.py` from the library's documentation strings (GAP-HARNESS-4, LABS-1.061). These are the readers' own descriptions of themselves: **not the E2 reader contracts**, which are written from the design documents and approved before any E2 question is authored (E2-D3); here they are only a supplement. Not implementation code and not system output.

The harness's reader templates (parameters, cited evidence, presented derivations) are in `evaluation/e2/readers.py`.

## `WorldModel.before(world, a, b, as_of=None, perspective='system')`

```text
Temporal succession of two descriptions: True if a certainly ends before b starts, False if b certainly
before a, None if they overlap or cannot be ordered. Succession says nothing about causation.
```

## `laboratory.calibration_status(wm, world, instrument, t, as_of=None, perspective='system')`

```text
Is `instrument` calibrated at t, for the perspective? holds / status / judgement as capable() (established,
expired, denied, disputed, not yet effective, not established; no new statuses; combined over the certificates
by rule Q, with the deciding claims in `support`), and every certificate whose
calibration content names the instrument, with its reference number, its own judgement and its evidence.
"not established" with no certificates means that no calibration is recorded at all.
```

## `WorldModel.causes_of(world, effect, t, as_of=None, perspective='system', _memo=None)`

```text
Every causal claim about what caused `effect` (an occurrence or an event description), judged for the
perspective. Claims stated about the effect itself are direct; claims stated about another description of the
same happening (or about the occurrence a description describes) are lifted, but only through describes links
the perspective accepts, and they keep their own provenance (plan 9.3). Each claim is reported with its level
(description / occurrence / mixed), the occurrences its cause is accepted as, its judgement (accepted,
disputed, denied, unreviewed, rejected) and its sources. Nothing is inferred from order or chained.

Occurrence check (LABS-1.011): each claim also reports the status (occurrence_status) of every occurrence it
involves, and `applies`: False when one of them is denied, None when one is disputed, True otherwise. A claim
about a denied occurrence stays visible as its source's account (its own judgement is unchanged), but it does
not answer what caused the happening, and a lifted claim never makes a denied occurrence accepted.
```

## `WorldModel.changes(world, subject, t1, t2, as_of=None, perspective='system')`

```text
State transitions of `subject` whose valid time intersects (t1, t2], judged for the world, perspective and
knowledge time (LABS-1.015 contract).

The subject's records are loaded once. Every start and end bound of their windows is a boundary; the judged
state is constant between boundaries, so judging at each boundary gives the whole timeline (no extra queries).
Tracks: each functional slot whose key includes the subject (values judged as in value_at, conflicts
included), and each other content involving the subject (holds / does not hold / UNKNOWN / DISPUTED).
- category "world-state": between two accepted states; "judgement": into or out of UNKNOWN or DISPUTED, never
  presented as proof of physical change. Accepted A, then only UNKNOWN, then accepted B != A is one world-state
  transition whose window is the UNKNOWN gap: the instant is never invented.
- window [earliest, latest] and `within`: "certain" if inside (t1, t2], "possible" if it overlaps it;
  transitions outside are not returned.
- explanations: only accepted initiates / terminates claims about a content that began / ended in the
  transition, and only if the event did not certainly start after the transition. A claim that fits several
  activations of the same content is listed on each as "ambiguous"; never chosen, never inferred from
  proximity. `began` / `ended` are views over the returned transitions.
```

## `WorldModel.compare_measurements(world, bearer, quality, t=None, as_of=None, perspective='system')`

```text
Compare the measurements the perspective accepts (v0.2 clarification B). Each pair is "possibly compatible"
(comparable and the ranges overlap: one value could explain both, which is not agreement), "incompatible"
(comparable and disjoint) or "incomparable" (different coverage levels, conditions or SI units, or valid
times that do not overlap), with the reason. Nothing is combined. status: DISPUTED if any comparable pair is
incompatible; otherwise the accepted measurements' status. Statements (no result record) are listed apart and
never compared with measurements; unaccepted measurements are listed as alternatives.
```

## `WorldModel.convert(value, unit, to=None)`

```text
A value in `unit` expressed in `to` (default: the SI unit); refused across dimensions.
```

## `WorldModel.effects_of(world, event, t, as_of=None, perspective='system')`

```text
The effects claimed for an event description: for each initiates / terminates claim, who claims it and the
perspective's judgement of the claim (accepted, unreviewed, rejected, denied, disputed), and separately the
judged state of the outcome just before the event starts and when it ends: the accepted world-state change.
A claim can be accepted while the state change is not (and the reverse); neither implies the other.
```

## `WorldModel.explain(world, type, roles, t, as_of=None, perspective='system')`

```text
Why does a content hold at t? The judged answer; the events claimed to have initiated it that ended by t,
with each claim's judgement; and for each such event, the causal claims about it (causes_of, on its
description and on the occurrences it is accepted as describing). An explanation is only what was asserted
and accepted: earlier events without causal claims are not causes.
```

## `WorldModel.facts_about(world, subject, t, as_of=None, perspective='system')`

```text
Every content (other than events and identity links) involving the subject that holds or is disputed at t,
from the canonical judgement (DI-1, LABS-1.038). Each entry: type, roles, params, `judgement` (established or
disputed), `status` (DISPUTED for a dispute), `support` (the deciding attestations), `assertions` and
`denials` (the deciding accepted ones on each side: both, for a polarity dispute), `conflicts` (attestations
of the contents in conflict under a declared or attested single-value constraint, including rivals that do
not mention the subject: seen from a place, the thing's other places) and `support_status` (the support's
status before constraints; DISPUTED for a polarity dispute). Q-B2, LABS-1.015.
```

## `WorldModel.frame_info(world, frame, t, as_of=None, perspective='system')`

```text
What is known about a spatial frame at t: its name, what it is attached to, its transforms to parent and
child frames (as stored: translation and rotation), and the things positioned in it.
```

## `WorldModel.holds(world, type, roles, t, as_of=None, perspective='system')`

```text
Does this content hold at t for the perspective? Evidence-backed status with polarity: the canonical
judgement (`judgement`) as an Answer. Role names are the type's core role names (`role_names`); any other is
refused with UnknownRoleError (LABS-1.052).
```

## `WorldModel.interval(world, description, as_of=None, perspective='system', _memo=None)`

```text
The occurrence interval given by an attestation of the description that the perspective can use (start
Window, end Window, record), or None. An unaccepted account's times are never used for a judgement.
```

## `laboratory.measurement_calibration(wm, world, bearer, quality, t=None, as_of=None, perspective='system')`

```text
For each measurement of `quality` of `bearer` (wm.measurements), each result record and each activity
instrument: the record's **stated** calibration reference, the **attested** calibration judged at the activity's
start (calibration_status), and the exact-text check of one against the other. The measurement's own acceptance
and usability are copied from wm.measurements unchanged: calibration never invalidates, discards or downgrades a
measurement, and an activity without an accepted account has no time, so its calibration is not judged (None).
```

## `WorldModel.measurements(world, bearer, quality, t=None, as_of=None, perspective='system')`

```text
Every stated value of `quality` of `bearer`, each with its attestation's judgement for the perspective
(accepted, unreviewed, rejected, retracted, superseded) and its provenance. Values reported by a result record
rest on result records (rests-on) and are measurements (with each record and the activity that produced it);
values without one are statements, with
their basis (a design specification by testimony, a reading noted without a record). If t is given, only
attestations that hold at t.
```

## `WorldModel.occurrence(world, occurrence, as_of=None, perspective='system')`

```text
A merged view of an occurrence. Conflicts stay visible and traceable; nothing is merged in storage.

- `descriptions`: the descriptions the perspective accepts as describing it (as `descriptions()`);
- `participants`: the core-role projection, unchanged since Core 0.3: for each core role name (a profile's own
  new role keeps its name) every participant with the descriptions and sources that name it;
- `accounts` (LABS-1.043, ER-5): every description linked to it by a visible describes claim, accepted or not,
  with its event type, sources, link judgement (`describes`, the canonical record's claim label at the
  account's start), account state (occurrence_status's vocabulary), world depth and roles by stored label;
- `roles` (ER-5): keyed by stored role label (`replacement:removed`), with its own name and core role, every
  player and the accounts naming it, and `constraints`: each applicable event-role constraint (ER-1, ER-2)
  with whether it applies and why, and the role's judgement by rule Q (ER-4): DISPUTED for two or more
  distinct players under the perspective's identity, established for one, with status and support. Several
  players of a role without an applicable, established constraint are a union, never a dispute.
  LABS-1.049 (DI-13): each constraint also gives its `multiplicity` ("one" or "set"), the `reason` for a
  dispute, and for "set" each compared account's set (`sets`); see `_event_roles`.
```

## `WorldModel.occurrence_status(world, occurrence, t, as_of=None, perspective='system', details=True, _memo=None)`

```text
Whether the occurrence happened, for the perspective (LABS-1.011): judged only from attestations of its own
existence (existence(existent: occurrence)), never from accepted descriptions, describes links or causal
claims. `status` is accepted, denied, disputed or "not established". Each description that some source links
to it is reported separately: its source, whether the perspective accepts the account (the description's own
attestation) and the describes link. An accepted account of a denied occurrence is representable and reported
as such.
```

## `organisation.office_holders(wm, world, office, context, t, as_of=None, perspective='system')`

```text
Who holds `office` in `context` at t, for the perspective.
- appointments: every appointment content for this office and context, each with its own judgement and evidence
  (established, denied, expired, not yet effective, disputed, not established);
- holders: the established ones;
- exclusive: the single-holder constraint's own judgement at t;
- conflict: when the constraint holds and more than one appointment is established: the constraint's support and
  each conflicting appointment's accepted attestations;
- status (rule C, increment C): DISPUTED on a conflict or a disputed appointment; None when holders are
  established without conflict (there is no single support status for several people, or for the office: each
  appointment keeps its own status); UNKNOWN when appointments exist but none is established; NOT_YET_KNOWN when
  there are none.
Nothing is inferred about anyone not mentioned.
```

## `WorldModel.poses(world, thing, t, as_of=None, perspective='system')`

```text
The thing's positions that hold at t, one per frame statement: frame, per-axis (lower, upper), orientation,
status and supporting attestations. Several positions in one frame are all listed, each with its own status:
a position in conflict with another (the positioned-in slot, A2) or disputed by an accepted denial (DI-1) is
DISPUTED, with its rivals in `conflicts`.
```

## `WorldModel.process_steps(world, process, t, as_of=None, perspective='system')`

```text
The occurrences accepted as part of a process occurrence at t, ordered by their descriptions' intervals,
each with its descriptions, interval, kinds and actors (from the perspective's accepted descriptions), and the
judgement and status of its part-of content: established, or disputed (DI-1: listed, never dropped).
```

## `WorldModel.transform_between(world, source, target, t, as_of=None, perspective='system', limit=None)`

```text
How `source` frame coordinates map into `target` at t: {"status", "transform" (q, t) or None, "chain" (the
shortest chain, each step with its direction and supporting attestations), "frames", "reason", "search"}.
INFERRED from the transforms that hold for the perspective; DISPUTED when chains disagree or use a disputed
transform (no transform is chosen); UNKNOWN when no chain exists or the search was truncated (see `search`;
a truncated search that reached the target returns its transform as an unverified candidate).
```

## `WorldModel.value_at(world, type, subject, t, as_of=None, perspective='system', key_role=None, value_role=None)`

```text
The value(s) of a relationship for `subject` at valid time t, for a perspective, as known at `as_of`.
key_role and value_role, when given, are checked as in holds() (LABS-1.052).
```

## `WorldModel.where(world, thing, frame, t, as_of=None, perspective='system', angle_tolerance=1e-09, limit=None)`

```text
The thing's position in `frame` at t, judged (A2, LABS-1.008). Every position statement that holds for the
perspective is a candidate: stated in `frame` (direct), or mapped into it through the shortest frame chain
(derived, INFERRED, citing the position and every transform). Candidates are compared, never merged:
overlapping ranges can both be true (compatible), disjoint ranges conflict, and orientations conflict when
their angular separation exceeds `angle_tolerance` (policy, default 1e-9 rad). A statement whose frame cannot
be related to `frame` is listed as incomparable, with the search metadata saying whether the search completed
or was truncated. Where chains disagree, the candidate has no position (none is chosen) and is DISPUTED.
```
